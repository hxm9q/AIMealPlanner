# AIMealPlanner

iOS-приложение для умного планирования питания с использованием AI. Генерирует персональные планы питания и рецепты на основе предпочтений пользователя, истории и профиля. Может найти любой рецепт блюда под разные потребности.

## Основные требования и особенности проекта

**Архитектура:** SwiftUI + MVVM с чётким разделением слоёв  
**Управление состоянием:** ViewState + BaseViewModel  
**AI-интеграция:** Groq API для генерации планов питания  
**Рецепты:** Spoonacular API для получения рецептов и деталей блюд  
**Аутентификация:** Firebase (GoogleService-Info.plist)  
**Хранение данных:** локально + история сессий  
**Утилиты:** Logger для отладки

> ⚠️ API-ключ хранится в проекте исключительно в демонстрационных целях.  
> В реальном продакшн-релизе ключ был бы скрыт (через backend, environment variables, CI/CD secrets или Keychain).

**Основные экраны приложения:**
1. Auth — авторизация пользователя
2. Home — расчет нормы калорий исходя из параметров пользователя 
3. Planner - AI-ассистент для генерации планов питания
4. History — история сгенерированных планов
5. Recipes — поиск рецептов и просмотр деталей блюд
6. Settings — настройки приложения и параметров пользователя
